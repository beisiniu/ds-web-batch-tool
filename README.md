# DeepSeek 网页批量处理工具

把 Excel/CSV 里的名单分批发给 DeepSeek 网页版，自动收结果、自动存盘、限流后能接着跑。

适合这类任务：期刊官网/供应商查询、学者信息查询、机构信息查询，以及任何“给一批名称，按固定字段返回 JSON”的重复工作。

---

## 推荐：网页控制台

双击 **start_ui.bat**，会自动打开浏览器（`http://127.0.0.1:8765`）。

1. 点左下角「登录设置」→ 按弹窗步骤从日常 Chrome 复制一次登录状态 →「从剪贴板导入并验证」。
2. 上传名单 → 选工作表和名称列 → 选「期刊 / 机构 / 学者」领域（自带领域提示词），或选「自由领域」自己写任务提示词；字段可以自由增删，说明可选。
3. 先点「试跑 3 条」确认格式，再点「保存并开始」正式跑。
4. 在任务页看实时进度、日志，下载 JSON / CSV。

**领域只是提示词模板，不是三套工具**：

- 期刊 / 机构 / 学者：固定的领域核查要点 + 你配置的字段 + 系统格式规则
- 自由领域：你写任务提示词 + 你配置的字段 + 系统格式规则

系统统一追加格式规则：只输出 JSON 数组、数量/顺序一致、名称原样保留、禁止编造 URL 或事实、无法确认用空字符串。字段说明可留空（预设已填好）；自由领域必须写提示词。每个任务独立保存在 `tasks/<任务ID>/`，有自己的输入副本、配置、进度和结果，互不干扰。

### 账号池（自动轮换）

复制 `accounts.example.yaml` 为 `accounts.yaml`（本地使用，已在 `.gitignore` 中），里面配置多个账号，每个账号一个独立的 Chrome 配置目录；token 存在各自 profile 里，不写进 yaml。

- 任务卡住超过 `stuck_switch_sec`（默认 **300 秒**）或遇到限流，自动切到下一个账号；
- 切换后在新账号里新开会话、重发任务说明，本地进度和断点不变；
- 切走的账号进入 `account_cooldown_sec`（默认 **600 秒**）恢复期；另一个账号也卡住时，等它恢复后再切回，形成循环；
- 任务页右上角显示当前账号，日志会打印切换记录；
- 「登录设置」里可以看到账号池、添加账号（从剪贴板导入）。

**同一个任务、同一份进度文件**，不会按账号复制任务。

## 命令行方式（备用）

首次使用命令行前，先复制 `config.example.yaml` 为 `config.yaml`，把输入文件改成你的路径。

1. 双击 **start.bat**。
2. 选 **1**，在弹出的 Chrome 里登录 DeepSeek。若右侧出现「微信快捷登录」，直接点绿色按钮最省事；否则用手机验证码或扫码。**必须用你主浏览器里同一个账号登录**（否则看不到原来的会话），登录后关掉欢迎弹窗，回到黑色窗口按回车。
3. 选 **9**，检查页面结构。正常会显示输入框定位 OK，并保存一张 `output/doctor.png`。
4. 选 **2**，试跑 3 条。跑完打开 `output/期刊元数据.json`，确认内容正确。
5. 确认无误后选 **3** 正式跑。中断、限流、关机后，再选 3 会自动从没做完的地方继续。

当前配置对应桌面上的 `期刊名_.xlsx`：共 **10105** 条，每批 50 条，约 **203** 批。

## 登录页打不开时：导入已登录浏览器的 token（推荐）

前提：你日常用的 Chrome 已经登录 DeepSeek，并且能正常聊天。

1. 在**日常 Chrome**里打开 `https://chat.deepseek.com/`。
2. 按 `F12` 打开开发者工具，切到 **Console**。
   如果提示“不要粘贴你不理解的代码”，先输入 `allow pasting` 回车。
3. 粘贴并执行下面这行：

   ```js
   copy(JSON.stringify({local: {...localStorage}, session: {...sessionStorage}, cookies: document.cookie}))
   ```

4. 双击 [import-session.bat](import-session.bat)（或 `start.bat` → 10）；网页控制台里点「登录设置」→「从剪贴板导入并验证」是同一套逻辑。
5. 看到“登录状态导入成功”后，再 `start.bat` → 2 试跑。

安全提示：这段内容里的 `userToken` 等同于账号登录权限。只在本机复制、导入；不要发到聊天、网页或别人电脑。导入成功后脚本会自动清空剪贴板。令牌保存在 `browser-profile/`，不要分享这个目录。令牌过期后重复一次即可。

## 它到底怎么工作

1. 启动一个**专用 Chrome 窗口**，登录状态保存在项目里的 `browser-profile/`，不会动你日常用的 Chrome。
2. 打开 DeepSeek 会话：优先用 `config.yaml` 里填的会话链接，否则自动新建，并发送一次“任务说明”（字段、JSON 格式、禁止编造 URL）。
3. 每次取 50 个名称，按编号排好发给 AI。
4. 等回答生成完（优先看 DeepSeek 自己的请求结束信号，其次看页面文字是否稳定），从代码块或页面文字里取出 JSON。
5. 解析、校验、按名称对回输入；**每完成一条就追加写入硬盘**。
6. 遇到“服务器繁忙/请求频繁”就按 1 分钟 → 3 分钟 → 10 分钟 → 30 分钟退避；重试用尽或累计等待过久会自动保存并退出，下次续跑。
7. 同一会话发满 8 批后自动新开会话并重新交代格式，避免上下文太长导致回答变差。

关键点：**进度不依赖 AI 会话，而依赖本地 `records.jsonl`**。所以会话丢了、网页刷新了、电脑重启了，都能接着跑。

## 文件说明

| 文件/目录 | 作用 |
|---|---|
| `config.example.yaml` | 命令行配置示例：复制为 `config.yaml` 后改输入路径 |
| `accounts.example.yaml` | 账号池示例：复制为 `accounts.yaml` 后填本地账号配置目录 |
| `start_ui.bat` | 打开网页控制台（推荐） |
| `start.bat` | 命令行菜单入口 |
| `login.bat` | 单独打开登录窗口 |
| `import-session.bat` | 从剪贴板导入已登录浏览器的 token |
| `tasks/<任务ID>/` | 网页控制台的任务：输入副本、`config.yaml`、进度、结果 |
| `output/records.jsonl` | **真正的进度文件**，每完成一条追加一行，别删 |
| `output/state.json` | 当前会话链接、批次计数、输入文件指纹 |
| `output/raw/` | 每次 AI 原始回复（页面文字 + 抓到的流式内容），排查问题用 |
| `output/期刊元数据.json` | 最终结果数组，和你的 `数据.txt` 同格式，可直接用 |
| `output/期刊元数据.csv` | 同内容的表格版（UTF-8 BOM，Excel 可直接打开） |
| `output/missing.csv` | 未完成/失败的清单 |
| `output/run.log` | 运行日志 |
| `browser-profile/` | DeepSeek 登录状态，**不要发给别人** |
| `tests/test_offline.py` | 离线自测：读表、解析、断点、导出 |

本仓库不包含浏览器登录状态、账号 token、任务数据、结果文件和本机配置；`browser-profile*`、`config.yaml`、`accounts.yaml`、`tasks/`、`output/`、`docs/` 已在 `.gitignore` 中。

`output/期刊元数据.json` 每次运行结束都会重新生成；即使生成失败，`records.jsonl` 里的数据也不会丢。

## 试跑后检查什么

**网页控制台**：看任务页的三项计数和结果表；完整文件在 `tasks/<任务ID>/output/result.json`。

**命令行**：选 2 跑完 3 条后：

1. 黑窗口最后应显示“最终进度：成功 3 / 10105”。
2. `output/期刊元数据.json` 应该是 3 个对象，字段为 `journal_name / official_url / provider / source_notes`。
3. `output/records.jsonl` 应该有 3 行 `"status": "ok"`。
4. 再选 4，确认“已完成 3，待处理 10102”。
5. 如果 3 条里 URL 或备注明显不对，先改 `config.yaml` 里的 `preamble`，再选 8 全新开始（会归档旧结果）。

这一步很重要：先用 3 条确认格式和字段，再让它跑一整天。

## 常用参数（config.yaml，从 config.example.yaml 复制）

| 配置 | 默认 | 说明 |
|---|---|---|
| `batch.size` | 50 | 每次发多少条。输出经常被截断就降到 30 或 20 |
| `batch.rotate_every_batches` | 8 | 同一会话发几批后新开，防止上下文超长 |
| `batch.cooldown_sec` | `[8, 25]` | 两批之间随机休息，降低限流概率 |
| `deepseek.conversation_url` | 空 | 填你手工建好、已交代格式的会话链接；留空则自动新建 |
| `deepseek.send_preamble` | auto | `auto` 只在脚本新建会话时发说明；`never` 适合你完全手工准备会话 |
| `deepseek.response_timeout_sec` | 1200 | 单批最多等 20 分钟（开联网搜索时一批可能很久） |
| `deepseek.verification_wait_sec` | 900 | 遇到验证码/登录页时最多暂停等你 15 分钟；完成验证会自动继续 |
| `accounts.stuck_switch_sec` | 300 | 回答多久没有进展就切换账号（5 分钟） |
| `accounts.account_cooldown_sec` | 600 | 切走的账号至少休息多久后可再切回（10 分钟） |
| `accounts.switch_on_rate_limit_after` | 0 | 第几次限流后换账号；0 = 第一次限流就换 |
| `network.rate_limit_backoff_sec` | `[60,180,600,1800]` | 限流等待阶梯 |
| `fields` | 4 个字段 | 用于 CSV 表头和缺失检查 |
| `match_field` | `journal_name` | 用哪个字段和输入名称对齐 |

命令行也可以临时覆盖：

```bat
.venv\Scripts\python.exe -m src.main run --limit 3
.venv\Scripts\python.exe -m src.main run --batch-size 30
```

## 换任务：学者、机构、其他名单

**网页控制台**：切领域卡片、增删字段即可；自由领域写一段任务提示词，格式规则由系统追加。

**命令行**：复制 `config.scholar.example.yaml` 为 `config.yaml`，至少改这几项：

- `input.file` / `input.column`
- `output.dir`（**一定要换**，否则会和期刊任务混在一个进度文件里）
- `fields` 和 `match_field`
- `preamble`（告诉 AI 要哪些字段、什么格式）

数据结构可以完全不同，只要 AI 按 `preamble` 输出 JSON 数组，工具就能解析、存档、导出。

## 中断、限流、续跑

- **每批结束**都会写 `records.jsonl` 并保存 `state.json`。
- **遇到验证码/登录页**：脚本会暂停发送，日志和任务页会提示；在脚本浏览器里完成验证后自动继续，不会重复提交本批。每批消息带「批次校验码」，恢复时如果发现这批已有回答会直接复用。等待超过 15 分钟会保存进度并停止。
- **账号池**：卡住或限流自动换账号，切换不丢进度；切走的账号休息 600 秒后可再切回，形成循环。
- **网页控制台**：点「停止」后进度保留，点「开始 / 继续」接着跑；每个任务独立，不会串数据。
- 按 `Ctrl+C` 或直接关掉黑窗口：已写入的记录不会丢；下次运行从“没完成的条目”继续。
- 限流：自动等待并重试；重试用尽或累计等待超过 2 小时会主动退出，进度保留。
- 续跑不会重新发送已完成的条目，也不会因为 AI 会话换了而重来。
- **不要同时开两个窗口跑同一个任务**，会重复发送。

怎么确认真的续跑了：选 4 看“已完成”数量；正式运行时日志会从“待处理 10102”开始，而不是从第 1 条。

## 结果核对与导出

**网页控制台**：任务页直接下载 JSON / CSV；「刷新结果」会在停止后重新生成结果文件。

**命令行**：

- 菜单 4：完成/失败/待处理数量。
- 菜单 5：重新生成 JSON/CSV（不联网）。
- 菜单 7：把 `failed` 的条目重新标记为待处理，下次运行会再试。
- `missing.csv`：每一条未完成的原因。
- `raw/`：AI 当时到底回了什么；解析失败时先看这里。

匹配规则：优先按 `match_field`（默认 `journal_name`）和输入名称对齐；如果 AI 返回条数刚好等于输入条数，则按顺序兜底。两者都会记录，不会静默丢数据。

## 注意事项（请先看）

1. **这不是 DeepSeek 官方 API**，是驱动你自己账号的网页。网页改版、风控策略变化都可能让它失效；账号使用风险由你承担。请控制频率，不要多账号/多实例并发。
2. 脚本不会改“智能搜索/深度思考”开关。因为查官网需要搜索，建议开始前在网页上确认“智能搜索”是开启状态；新会话若重置了开关，需要手动再开。
3. 开联网搜索时，一批 50 条可能要几分钟到十几分钟，203 批可能跑一整天甚至更久。这是正常的，进度会一直保存。
4. 第一次正式跑之前，建议把 `期刊名_.xlsx` 和 `output/` 各备份一份。
5. 登录状态在 `browser-profile/`，等同于你的账号，不要拷贝给别人。
6. `output/` 里的数据可能包含未公开的整理结果，分享前自行检查。
7. 账号池是多个你自己的账号；DeepSeek 可能同时按 IP 限制，多账号也有平台条款/风控风险，请自己控制频率和范围。

如果哪天觉得网页限流太折腾：同样的表格、批次、断点逻辑，把“发送消息”换成 DeepSeek 官方 API 即可，稳定性和速度会好很多，成本也很低。

## 出问题怎么查

| 现象 | 处理 |
|---|---|
| 一直停在“等待登录” | 选 1 重新登录；确认弹窗里登录的是同一个账号 |
| 登录页二维码空白 / 手机验证码没反应 | 先等 15 秒或按 `Ctrl+R` 刷新；仍空白就直接用手机验证码，不走微信。多半是 Clash/v2ray 系统代理干扰，`config.yaml` 里 `browser.no_proxy: true` 会让脚本浏览器绕过代理；如果仍不行，临时退出 Clash 再登录。脚本会自动关闭上次残留的脚本 Chrome，不会碰你日常浏览器。**二维码和验证码都走不通时，直接用 `import-session.bat` 从已登录的 Chrome 导入 token（见上文）。** |
| 找不到输入框 / 发送不出去 | 选 9 生成 `output/doctor.png`，看页面是否有遮挡弹窗；把截图和 `run.log` 发我 |
| AI 回复不是 JSON | 看 `output/raw/` 最新文件；把 `batch.size` 降到 20~30；或把 `preamble` 写得更严格 |
| 某几条一直失败 | 选 7 重试；仍失败就看 `missing.csv` 和对应 `raw/` |
| 输入文件换了导致停止 | 选 8 全新开始（旧结果会归档到 `output/archive/`），或改 `output.dir` |
| 想从头再跑 | 选 8；不会删除旧数据，会先归档 |
| 提示无法启动 Chrome / 配置目录被占用 | 关掉之前脚本弹出的 Chrome 窗口（或重启电脑）再试；仍不行可删除 `browser-profile/` 后重新登录（只是重新登录，不影响数据） |

运行环境已经装好：Python 3.10 + Playwright 1.64 + 本机 Chrome。换电脑时双击 `start.bat` 会自动创建环境和安装依赖。
